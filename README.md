# Riverside Garden Villa

Static first-iteration marketing website and Instagram link page for Riverside Garden Villa, a private 3-bedroom riverside villa in Puncak.

## Live URLs

- Website: https://riverside-garden-villa.vercel.app
- IG links page: https://riverside-garden-villa.vercel.app/links

## Project Contents

- `index.html` — main SEO landing page
- `links.html` — branded Linktree-style page for Instagram bio
- `styles.css` — brand styling and responsive layout
- `assets/` — villa photos and logo used by the website
- `BRAND_GUIDELINES.md` — positioning, voice, color, typography, SEO, and visual guidance
- `vercel.json` — Vercel config

## Brand Summary

Riverside Garden Villa is positioned as a warm, private riverside escape in Puncak for families and close groups. The design direction is refined but approachable: garden green, warm cream, river stone, wood, terracotta, and natural photography.

Core line:

> Your private riverside escape in Puncak.

## Development

This is a static site. Open `index.html` directly or serve locally:

```bash
python3 -m http.server 8787
```

Then visit:

```text
http://localhost:8787
```

## Deployment

The project is deployed on Vercel.

```bash
vercel deploy --prod
```
